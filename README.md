# THAMBAPANNI Travel Website

A simple and modern travel website built with HTML and CSS. Explore popular places in Sri Lanka, international destinations, and online travel packages.

## Features

- **Popular Places:** Discover exclusive and trending destinations in Sri Lanka.
- **Travel Outside:** Explore international travel options with detailed packages.
- **Online Packages:** Choose from curated travel packages with pricing and features.
- **Responsive Design:** Clean and modern layout for desktop and mobile.
- **Easy Navigation:** Simple navigation bar and call-to-action sections.

## Project Structure

```
index.html
onlinepackage.html
traveloutside.html
style.css
images/
    (all images used in the site)
```

## Getting Started

1. **Clone the repository:**
    ```sh
    git clone https://github.com/yourusername/Travel-website.git
    ```
2. **Open the project folder.**
3. **Open `index.html` in your browser to view the site.**
